# Material Assets Registry — WPF paging-приложение для учёта материальных ценностей

WPF-приложение на C#, построенное на страничной модели (`Page` + `NavigationWindow`), для учёта материальных ценностей: компьютеров, мониторов, принтеров и другого оборудования, закреплённого за подразделением. Приложение загружает архив из Excel, XML или базы данных, позволяет просматривать и редактировать записи, а также формировать выборки по заданным критериям.

## Возможности

- **Загрузка архива** из одного из трёх источников на выбор пользователя: Excel (`.xlsx`), XML (`baza.xml`) или базы данных.
- **Просмотр архива** — вывод всех записей в табличном виде.
- **Добавление** новых записей в архив.
- **Удаление** существующих записей.
- **Редактирование** отдельных полей записи: количество, стоимость, срок службы.
- **Формирование списка на списание** — вывод предметов, у которых истёк срок службы к заданному году.
- **Топ-5 самых долгосрочных предметов** — вывод пяти предметов с наибольшим сроком службы.
- Если наименование предмета состоит из двух слов, они автоматически объединяются знаком подчёркивания (например, «Жёсткий_диск»).
- Навигация между страницами реализована как через гиперссылки, так и программно.

## Структура данных

Каждая запись архива содержит:

| Поле | Описание |
|---|---|
| Наименование | Название предмета (учёта) |
| Инвентарный номер | 4-значный номер |
| Номер лаборатории | Помещение, за которым закреплён предмет |
| Год приобретения | Год покупки |
| Месяц приобретения | Месяц покупки |
| Стоимость | Стоимость в денежных единицах |
| Срок службы | Срок службы в годах |
| Количество | Количество единиц предмета |

Пример данных приведён в файле `baza.xml`.

## Архитектура (страничная модель WPF)

Вместо привычного `Window` в качестве контейнера верхнего уровня используется класс `System.Windows.Controls.Page`. Каждое действие (загрузка архива, просмотр, добавление, удаление, формирование выборок) реализовано на отдельной странице.

- **`MainWindow`** — унаследован от `NavigationWindow` (окна с кнопками «вперёд»/«назад») и служит контейнером для страниц.
- **Гиперссылки** (`Hyperlink` со свойством `NavigateUri`) используются для перехода между страницами прямо из разметки XAML.
- **Программная навигация** реализована через `NavigationService.GetNavigationService(this)` и метод `Navigate()` — используется, например, после выполнения действия (сохранения записи, удаления и т.д.), чтобы автоматически вернуть пользователя на нужную страницу.

## Требования

- Windows
- .NET 6 (`net6.0-windows`) с поддержкой WPF (workload «.NET desktop development» в Visual Studio)
- Для загрузки из Excel через COM-интеграцию — установленный Microsoft Excel и раскомментированная ссылка `Microsoft.Office.Interop.Excel` в `Lab7.csproj` (по умолчанию отключена)

## Запуск

1. Откройте `WpfApp1.sln` в Visual Studio.
2. Соберите и запустите проект.
3. В главном меню выберите источник данных для загрузки архива: Excel, XML (`baza.xml`) или база данных.
4. После загрузки архива переходите между страницами через меню/гиперссылки, чтобы просмотреть данные, добавить/удалить записи, отредактировать реквизиты или получить нужные выборки (список на списание, топ-5 по сроку службы).

## Технологии

- C#, WPF (`System.Windows.Controls.Page`, `NavigationWindow`, `Frame`, `NavigationService`)
- Работа с XML (`System.Xml`)
- Опционально — `Microsoft.Office.Interop.Excel` для загрузки из Excel
